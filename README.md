# D 项目 C / J / F / E 落地页

此仓库仅用于独立域名的静态落地页部署，不包含后台或数据库副本。

| 版本 | 路径 |
| --- | --- |
| C | `/` |
| J | `/j/` |
| F | `/f/` |
| E | `/e/` |

本站另已加入 I（`/i/`）和 K（`/k/`）版，共六个版本。沿用现有后台、订单归类和 LINE 分组。

FB 像素按固定仓库编号 `copy1` 与版本独立读取 `repository_fb_pixels`；在后台「复制仓库一 · monofhj.com」配置。每版最多 5 个，空配置或读取失败不会回退共用像素。同一个像素 ID 若跨站重复配置，事件仍汇入同一个像素。

绑定新域名前，请在此仓库的 **Settings → Pages → Custom domain** 填写新域名，并按 GitHub 提示设置 DNS。不要复制旧仓库的 `CNAME` 文件，也不要把同一个域名同时绑定两个 Pages 仓库。
