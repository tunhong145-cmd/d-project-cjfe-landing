# D 项目 C / J / F / E 落地页

此仓库仅用于独立域名的静态落地页部署，不包含后台或数据库副本。

| 版本 | 路径 |
| --- | --- |
| C | `/` |
| J | `/j/` |
| F | `/f/` |
| E | `/e/` |

四个版本沿用现有 D 项目的 Supabase 后台。各版本的订单标记、FB 像素筛选与 LINE 分组保持原逻辑，因此更改后台的共用配置也会影响此仓库中对应的版本。

绑定新域名前，请在此仓库的 **Settings → Pages → Custom domain** 填写新域名，并按 GitHub 提示设置 DNS。不要复制旧仓库的 `CNAME` 文件，也不要把同一个域名同时绑定两个 Pages 仓库。
